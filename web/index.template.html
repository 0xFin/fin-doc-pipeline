页面脚本没有加载

处理逻辑已经内嵌在这个文件里，正常情况双击就能直接用。看到这条提示，说明 index.html 不完整，或者被浏览器扩展、安全策略拦截了。

修复：运行 npm run build 重新生成，或双击 start.command 用本地服务打开。

输入文本

拖拽文本到这里，或点击选择

可一次选择多个文件；编码自动识别（UTF-8 / UTF-16 / GBK / GB18030 / Big5）；HTML / RTF 会先去标记。DOCX / EPUB / PDF 请用命令行。

处理方式

排版选项

{num}章号，按位数补零 {title}副标题 {prefix}分组前缀，如「番外」 {unit}章 / 回 / 节 {raw}原始标题整行

txt / md 输出会自动在最前面加 ## ；docx / PDF / EPUB 使用真正的标题样式，不会出现字面 #。

输出格式

GBK / Big5 / GB18030 输出需要系统 iconv，浏览器版不支持，请用命令行 --encoding；UTF-16 默认带 BOM。
